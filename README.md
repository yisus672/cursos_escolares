# Escuela de JavaScript 2026 — De cero a Master en JavaScript

**Domina el desarrollo FullStack con JavaScript desde cero con HTML, CSS, JavaScript, Webpack, Node.js, Express, etc.**

Repositorio de prácticas, apuntes y proyectos realizados durante el curso en Udemy, impartido por Alex Roel ChB.

> **Estado actual:** En progreso. Se irá actualizando conforme se completen las secciones del curso.

---

## Descripción del curso

El curso ofrece una ruta estructurada para dominar el desarrollo web **FullStack con JavaScript**, partiendo desde los fundamentos de la web y la maquetación con HTML5 y CSS3 hasta la programación en JavaScript, empaquetado con Webpack y desarrollo backend con Node.js, Express y MongoDB.

- **Plataforma:** Udemy
- **Instructor:** Alex Roel ChB
- **Entorno de desarrollo:** Visual Studio Code
- **Duración aproximada:** 31 horas de video
