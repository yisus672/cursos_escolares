# Escuela de JavaScript 2026 — De cero a Master en JavaScript

Repositorio de prácticas, apuntes y proyectos realizados íntegramente en **[Visual Studio Code](https://code.visualstudio.com/)** durante el curso **[Escuela de JavaScript 2026 - De cero a Master en JavaScript](https://www.udemy.com/course/curso-completo-javascript/)** en Udemy, impartido por **Alex Roel ChB**.

> **Estado actual:** Avanzando en la **Sección 8** del curso (_CSS Flexbox_ / maquetación inicial) tras completar la primera página web con HTML5, multimedia y estilos base en CSS. Todo el desarrollo se realiza en Visual Studio Code y el repositorio se irá actualizando conforme avance hacia JavaScript, Webpack y el backend.

## Descripción del curso

El programa ofrece una ruta estructurada para dominar el desarrollo web **FullStack con JavaScript**, partiendo desde los fundamentos de la web y la maquetación con HTML5 y CSS3 hasta la programación en JavaScript, empaquetado con Webpack y desarrollo backend con Node.js, Express y MongoDB ([CourseVania](https://coursevania.com/courses/escuela-de-javascript-2022-de-cero-a-master-en-javascript/)).

- **Plataforma:** [Udemy](https://www.udemy.com/course/curso-completo-javascript/)
- **Instructor:** Alex Roel ChB
- **Entorno de desarrollo:** [Visual Studio Code](https://code.visualstudio.com/)
- **Duración aproximada:** 31 horas de video ([CourseVania](https://coursevania.com/courses/escuela-de-javascript-2022-de-cero-a-master-en-javascript/))
- **Enfoque:** Desarrollo Web FullStack (Frontend + Backend)

## Progreso del curso

Seguimiento basado en la estructura de secciones del programa ([CourseVania](https://coursevania.com/courses/escuela-de-javascript-2022-de-cero-a-master-en-javascript/)):

- [x] **Sección 1 — Primeros pasos en la Web:** Temario, metodología y materiales del curso.
- [x] **Sección 2 — Configuración de entorno de desarrollo:** Funcionamiento de la web, Visual Studio Code y tecnologías principales.
- [x] **Sección 3 — Introducción a HTML:** Instalaciones necesarias, Node.js y terminal.
- [x] **Sección 4 — Estructura de una página HTML:** Etiquetas de texto, encabezados, párrafos, imágenes, atributos, vínculos y listas.
- [x] **Sección 5 — Etiquetas multimedia y formularios:** Semántica HTML, citas, formularios, tipos de `input`, validación, metadatos, Open Graph y favicon.
- [x] **Sección 6 — Introducción a CSS:** Imágenes, etiquetas de audio/video y primeros estilos.
- [x] **Sección 7 — Posicionamiento de elementos (Clon de Google):** Selectores, herencia, colores, pseudo-clases, cascada, especificidad y modelo de caja.
- [ ] **Sección 8 — CSS Flexbox (Clone de Yahoo!)** _(En curso)_: Variables CSS, flotación, desbordamiento, posicionamiento, `z-index` y estructura del clon.
- [ ] **Sección 9 — Portafolio Personal con Flexbox:** Diseño completo desde cero con contenedores flexibles y alineamiento.
- [ ] **Siguientes módulos — JavaScript, Webpack y Backend:** Programación en JavaScript, interactividad, Webpack, Node.js, Express y MongoDB.

## Cómo abrir y ejecutar el proyecto en Visual Studio Code

1. Clona este repositorio y ábrelo en Visual Studio Code:

   ```bash
   git clone https://github.com/yisus672/cursos_escolares.git
   cd cursos_escolares
   code .
   ```

2. Abre `index.html`, `multimedia.html` o `evento.html` con la extensión **Live Server** en Visual Studio Code (o directamente en tu navegador).

_(Cuando se agreguen prácticas de JavaScript con Node.js o Webpack, podrás ejecutar `npm install` y `npm start` desde la terminal integrada de VS Code)._
